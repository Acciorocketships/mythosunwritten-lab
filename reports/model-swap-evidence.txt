4. A name where the reader wants an id, put through tools/read_spot.gd

   examine target=Pell          | action=examine    params={ "target": "Pell" }           | catalogue:  | tool={  }
   examine #3                   | action=examine    params={  }                           | catalogue: examine needs target | tool={  }
   examine target=#3            | action=examine    params={ "target": 3 }                | catalogue:  | tool={  }
   recall                       | action=-          params=-                              | catalogue: nothing was chosen | tool={  }
   say target=#Sable text=hi    | action=say        params={ "target": "#Sable", "text": "hi" } | catalogue: say's target must be an id | tool={  }

   examine's target is an id-or-name, so a name there is legal and the
   reader passes it through; say's target is an id, so the catalogue
   faults a name -- and a faulted action is refused before
   ActionScene.note_action, so the character's count of actions carried
   out never moves and ModelMind offers the same line again forever.
